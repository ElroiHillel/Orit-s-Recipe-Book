# מתכונית

אפליקציית אנדרואיד שמקבלת צילום מסך, תמונה או טקסט של מתכון, שולחת ל-Gemini, ומחזירה מתכון מסודר לפי תבנית קבועה. כל האפליקציה היא `app/src/main/assets/index.html` בתוך WebView. אפשר לפתוח את הקובץ הזה גם ישירות בדפדפן מחשב לבדיקות UI.

## בניית APK בענן (בלי Android Studio)

1. יוצרים ריפו **פרטי** חדש בגיטהאב (פרטי, כי מפתח החתימה נמצא בתוכו).
2. מעלים אליו את כל התיקייה הזו (כולל `.github`), ל-branch בשם `main`:
   ```
   git init -b main && git add . && git commit -m "Matkonit"
   git remote add origin https://github.com/<user>/matkonit.git && git push -u origin main
   ```
3. בלשונית Actions רץ אוטומטית "Build APK" (בערך 3-5 דקות). בסיום, בתוך הריצה, תחת Artifacts, מורידים `matkonit-apk` (קובץ zip עם `matkonit.apk`).
4. מעבירים לטלפון ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

כל push ל-main בונה גרסה חדשה. כדי שתותקן כעדכון מעל הקודמת ולא תמחק את ספר המתכונים, מעלים `versionCode` ב-`app/build.gradle`. החתימה קבועה (`app/matkonit.keystore`), אז עדכונים עובדים.

## בנייה מקומית

Android Studio > Open > התיקייה הזו > Build > Build APK(s). או משורת פקודה עם Gradle 8.7+ ו-JDK 17: `gradle assembleRelease`.

## מה האפליקציה עושה

- העלאת תמונות (כמה ביחד, מהגלריה או מהמצלמה), הדבקת טקסט, או **שיתוף** צילום מסך/טקסט מכל אפליקציה אחרת ישירות ל"סידור מתכון".
- עריכה ידנית עם תצוגה מעוצבת, תיקונים בעזרת ג'ימיני (כפתורים מהירים וטקסט חופשי), חזרה לגרסה קודמת.
- העתקה, שיתוף (מותאם לוואטסאפ), שמירה כ-txt / md / html לתיקיית הורדות/Matkonit, ו-PDF דרך מסך ההדפסה של אנדרואיד.
- ספר מתכונים עם חיפוש, שנשמר בטלפון.
- הגדרות: מפתח ומודל, טעינת רשימת המודלים מהחשבון, temperature / top-P / אורך / חשיבה / timeout, רזולוציית תמונה, שפה, יחידות, התאמת מנות, מידע חסר, 13 מתגי ניסוח, סגנון פלט, תבנית עריכה חופשית, הוראות קבועות, כפתורי תיקון מהיר, פרומפט מערכת ידני, פורמט ושם קובץ, ערכת צבעים וגודל טקסט, גיבוי ושחזור.
